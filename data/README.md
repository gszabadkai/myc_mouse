# Data

This directory contains data files for the myc_mouse project.

## Small reference files (tracked in git)

- `coldata.csv` — sample/column metadata
- `OXPHOS_subunits.csv` — OXPHOS subunit gene list
- `cell_death_genes_consolidated.csv` — consolidated cell death gene list
- `felsher_integrative_signature.csv` — Felsher integrative signature
- `mitocarta_pathways.csv` — MitoCarta pathway annotations
- `myc_signature_genesets.gmx` — Myc signature gene sets
- `FULL.DAT.COL.DATA.txt` — column metadata for full dataset

## Large files (NOT tracked in git)

These files are available via the shared Google Drive folder:

- `FULL.DAT.csv` / `FULL.DAT_copy.csv` — full expression dataset (~7 MB each)
- `Human_MitoCarta3_0.xls` — Human MitoCarta 3.0 (~10 MB)
- `Mouse_MitoCarta3_0.xls` / `Mouse.MitoCarta3.0.xls` — Mouse MitoCarta 3.0 (~10 MB each)
- `cell-death/` — cell death analysis data files
