###Overall project description

R bioinformatics pipeline analysing bulk RNA-seq from MMTV-Myc transgenic mice.
4 groups x 6 replicates: 6W_neg, 6W_pos, 12W_neg, 12W_pos.
Investigates Myc-driven transcriptional and mitochondrial changes across two timepoints.

## Commands
- Run a script: `Rscript scripts/XX_script_name.R`
- Scripts must be run in numerical order (00-12); each depends on prior outputs
- Setup script: `scripts/00_setup_packages.R` (loaded by all others via `source()`)

## Project structure
- `scripts/` — numbered R pipeline (00-12), run sequentially
- `data/` — input data (count matrix, MitoCarta3.0, cell death CSVs, gene sets)
- `results/` — intermediate RDS files (gitignored, generated at runtime)
- `outputs/` — figures and tables (gitignored, generated at runtime)
- `functions/` — shared utility functions
- `external/mitotyping/` — Monzel et al. (2025) mitoPPS reference code

## R coding rules
- Never use `print(n=X)` after `head()` — use `head(X) %>% print()` or `tibble %>% print(n=X)`
- Always use `dplyr::count()`, not bare `count()`, to avoid namespace conflicts
- Use ASCII-only strings (no Unicode escapes) for cross-platform compatibility
- Dependencies are centralised in `00_setup_packages.R`; individual scripts should not add redundant `library()` calls
- Use DESeq2 normalised counts (not VST) for mitoPPS calculations
- Handle latin1/cp1252 CSV encoding defensively at read stage
- Gene-to-pathway mapping uses MitoCarta3.0 Sheet 4 with `splitstackshape::cSplit`
- mt-* genes (13 mtDNA-encoded) must be separated from nuclear-encoded pathways to avoid skewing mitoPPS

## Key methods
- DESeq2 interaction model: `~ timepoint * myc_status` with five contrasts
- fGSEA: Wald-statistic ranked gene lists, detects absolute transcriptional enrichment
- mitoPPS: pairwise ratio-based (Monzel et al. 2025), detects relative resource reallocation within the mitochondrial compartment
- Cell death analysis: 15 regulated cell death modalities from Tang et al. 2024
